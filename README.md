## Update your GitHub Pages repository

1. Extract the ZIP. **Upload the extracted files**, not the ZIP archive itself.
2. At the repository root, replace `index.html`, `research.html`, `talks.html`, `events.html` and upload the new `cv.html`. All five include consistent top navigation.
3. Replace `css/phase1.css` inside the `css` folder, and upload `assets/Johan_Dinesen_CV_public.pdf` inside the `assets` folder.
4. Keep your existing custom-domain `CNAME` file and `assets/profile.jpg` photograph. They are **not in this ZIP**, so do not delete them.
5. Your previous `publications.html` or `teaching.html` files, if any, will still exist until you explicitly delete them from GitHub. This ZIP does not contain those files.
6. Commit and verify the five links after the GitHub Pages deployment completes. If the old page remains in your browser, use a hard refresh or private window.

The full CV PDF and website content are based on the September 2026 CV; update them when awards, dates, and appointments change.
